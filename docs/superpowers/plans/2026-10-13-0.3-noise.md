# 0.3 Milestone 2: Noise Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a student add depolarizing and readout noise to the whole circuit from a noise panel, see the results with and without noise side by side, watch the Bloch arrows shrink as noise builds up, and export the noise to Qiskit and Cirq. All of it stays exact and matches Qiskit within 1e-9.

**Architecture:** The circuit gains an optional `noise: {oneQubit, twoQubit, readout}`. Gate noise makes a circuit use the density-matrix engine, which applies Qiskit's `depolarizing_error(p, k)` channel after each gate. Readout error is classical. On final probabilities it flips each bit with probability p (`withReadout`). For a measurement that a condition reads, the engine keeps the "reading came out wrong" part in ρ's entries between the measured qubit's 0 and 1. Those entries are empty after the measurement, so this exactly matches a separate record bit without using more memory. Every step's state is written straight into one packed buffer. The results panel runs a second simulation of the same circuit without noise for the comparison.

**Tech Stack:** TypeScript, React, Zustand, Vitest, Playwright. Python in the quantum-lab image: Qiskit 2.5.2 with Aer, Cirq 1.7.0 and pyQuil 4.22.0.

**Spec:** `PLAN.md`, section "Version 0.3 plan" (In, Technical design, Milestones item 2). Project rules: `CLAUDE.md`. The decisions made on Oct 13, 2026 are listed under "Decisions" below.

## Decisions

- **Noise panel:** a "Noise" button in the circuit toolbar, next to "+ Add qubit", opens three sliders under the toolbar. The summary line says "noise on".
- **Ranges:** gate errors from 0 to 10%, readout from 0 to 20%, in steps of 0.1%. Rates snap to 0.001. If all three rates are zero, the circuit has no noise.
- **What gets noise:**
  - A one-qubit gate gets `oneQubit`. A gate on two or more qubits (CNOT, CZ, SWAP and Toffoli) gets `twoQubit`, as a depolarizing channel on all of its qubits; Toffoli gets a 3-qubit one.
  - Measurements and resets get no gate noise.
  - A conditional gate gets its noise only when it runs. Checked in the image: Aer applies noise inside `if_test`.
- **Readout error:**
  - It flips every recorded bit, including the mid-circuit records that conditions read, as Qiskit Aer's `ReadoutError` does. Checked in the image: a misread record drives the condition in Aer and in Cirq's `confusion_map`.
  - The "If you measured now" chart applies it to every qubit.
- **Engine:** `usesDensity = isDynamic || hasGateNoise`. Readout error alone doesn't change the state, so such circuits keep the state vector. They also keep the 12-qubit limit and their amplitudes. This is narrower than PLAN's "anything with noise uses the density matrix", but just as exact.
- **Ideal vs noisy:** a second Web Worker simulates `withoutNoise(circuit)` when there is gate noise. With readout error only, the ideal chart is the state's own probabilities.
- **Export statistics:** use the bound the dynamic-circuit tests already use (1000 shots, 5σ + 0.01) without a fixed seed. Downloads are student-facing, so they don't carry a test seed.
- **Lab `/run`:**
  - Qanvas sends `noise` and `measured` only when `/api/health` lists a `"noise"` feature.
  - Without it, a circuit that is noisy or dynamic and above the browser limit shows the size note.
  - The bridge change is written as a spec for a separate quantum-lab session (Task 9).
- **Undo:** a run of noise changes with no other edit in between (a slider being dragged) is one undo step.

```ts
  return circuit.noise !== undefined && (circuit.noise.oneQubit > 0 || circuit.noise.twoQubit > 0 || circuit.noise.readout > 0);
}

export function hasGateNoise(circuit: Circuit): boolean {
  return circuit.noise !== undefined && (circuit.noise.oneQubit > 0 || circuit.noise.twoQubit > 0);

/** Gate noise mixes the state; readout error alone only changes what measurements report, so it keeps the state vector. */
export function usesDensity(circuit: Circuit): boolean {
  return isDynamic(circuit) || hasGateNoise(circuit);
}

/** The most qubits the browser simulates this circuit with; above it, only quantum-lab's Qiskit Aer runs it. */

  return usesDensity(circuit) ? DENSITY_QUBITS : BROWSER_QUBITS;

export function withoutNoise(circuit: Circuit): Circuit {
  const plain = { ...circuit };
  delete plain.noise;
  return plain;

export function gateError(op: Operation, noise: Noise | undefined): number {
  if (!noise || op.gate === 'M' || op.gate === 'RESET') return 0;
  return operationQubits(op).length === 1 ? noise.oneQubit : noise.twoQubit;
```

```ts
/**
 * Writes the density matrix before any column, then after each one, into `re` and `im` (step k at k·4ⁿ),
 * so a long circuit keeps a single copy of each snapshot.
 */
export function simulateDensity(circuit: Circuit, re: Float64Array, im: Float64Array): void {
  if (circuit.qubits > DENSITY_QUBITS) throw new Error(`The density-matrix simulator works with up to ${DENSITY_QUBITS} qubits`);
  const size = 1 << (2 * circuit.qubits);
  const partway = partwayMeasurements(circuit);
  re[0] = 1;
  circuit.columns.forEach((column, c) => {
    re.copyWithin((c + 1) * size, c * size, (c + 1) * size);
    im.copyWithin((c + 1) * size, c * size, (c + 1) * size);
    const rho: DensityMatrix = { qubits: circuit.qubits, re: re.subarray((c + 1) * size, (c + 2) * size), im: im.subarray((c + 1) * size, (c + 2) * size), mixed: true };
    for (const op of column) applyOperation(rho, op, (q) => partway.has(`${c}:${q}`));
  });
}
```

```ts
/** Every step's state, one after another: the state before any column, then after each one. */
export interface Simulation {
  qubits: number;
  mixed: boolean;
  re: Float64Array;
  im: Float64Array;
}

function stateSize(qubits: number, mixed: boolean): number {
  return mixed ? 1 << (2 * qubits) : 1 << qubits;
}

/** A view of one step's state inside the simulation's buffers; steps past the end give the last one. */
export function stateAt(simulation: Simulation, step: number): QuantumState {
  const { qubits, mixed } = simulation;
  const size = stateSize(qubits, mixed);
  const k = Math.min(step, simulation.re.length / size - 1);
  const re = simulation.re.subarray(k * size, (k + 1) * size);
  const im = simulation.im.subarray(k * size, (k + 1) * size);
  return mixed ? { qubits, re, im, mixed: true } : { qubits, re, im };
}

export function simulateSteps(circuit: Circuit): Simulation {
  const errors = validateCircuit(circuit);
  if (errors.length > 0) {
    throw new Error(`Invalid circuit: ${errors.map((e) => e.code).join(', ')}`);
  }
  const { qubits } = circuit;
  const mixed = usesDensity(circuit);
  const size = stateSize(qubits, mixed);
  const re = new Float64Array((circuit.columns.length + 1) * size);
  const im = new Float64Array(re.length);
  if (mixed) {
    simulateDensity(circuit, re, im);
  } else {
    re[0] = 1;
    circuit.columns.forEach((column, c) => {
      re.copyWithin((c + 1) * size, c * size, (c + 1) * size);
      im.copyWithin((c + 1) * size, c * size, (c + 1) * size);
      const state = stateAt({ qubits, mixed, re, im }, c + 1) as StateVector;
      for (const op of column) applyOperation(state, op);
    });
  }
  return { qubits, mixed, re, im };
}

/** Returns the state before any column, then after each column: `columns.length + 1` states. */
export function simulate(circuit: Circuit): QuantumState[] {
  const simulation = simulateSteps(circuit);
  return Array.from({ length: circuit.columns.length + 1 }, (_, k) => stateAt(simulation, k));
}
```

```python
def misreading(p):
    return Kraus([math.sqrt(1 - p) * np.eye(2), math.sqrt(p) * np.array([[0, 1], [1, 0]])])


def when_recorded(channel, value):
    """`channel` on the target only where the record qubit (qarg 0) holds `value`."""
    on, off = np.diag([1 - value, value]), np.diag([value, 1 - value])

def noisy_density(circuit):
    """The final state with Qiskit Aer's depolarizing channels after each gate.

    Each measurement a condition reads is copied onto an extra record qubit, which the readout error
    can flip, so the condition reads the record rather than the qubit, like a classical bit on hardware.
    The record qubits are traced out at the end.
    """
    n, rates = circuit["qubits"], circuit["noise"]
    partway = partway_measurements(circuit)
    records = {key: n + i for i, key in enumerate(sorted(read_measurements(circuit)))}
    total = n + len(records)
    dm = DensityMatrix.from_label("0" * total)
    record_of = {}
    for c, column in enumerate(circuit["columns"]):
        for op in column:
            name, qubits = op["gate"], op.get("controls", []) + op["targets"]
            if name == "M":
                for q in op["targets"]:
                    if (c, q) in partway:
                        dm = dm.evolve(MEASURE, qargs=[q])
                    if (c, q) in records:
                        record = records[(c, q)]
                        dm = dm.evolve(RECORD, qargs=[q, record])
                        if rates["readout"] > 0:
                            dm = dm.evolve(misreading(rates["readout"]), qargs=[record])
                        record_of[q] = record
                continue
            if name == "RESET":
                dm = dm.evolve(RESET, qargs=op["targets"])
                continue
            p = rates["oneQubit"] if len(qubits) == 1 else rates["twoQubit"]
            if "condition" in op:
                condition, target = op["condition"], op["targets"][0]
                record = record_of[condition["qubit"]]
                plain = {key: value for key, value in op.items() if key != "condition"}
                unitary = to_qiskit({"qubits": 1, "columns": [[{**plain, "targets": [0]}]]}).to_gate()

        flipped = p[np.arange(len(p)) ^ (1 << (qubits - 1 - q))]
        p = (1 - readout) * p + readout * flipped
    return p
```

```ts
/** What measuring every qubit reports when each reading comes out wrong with probability `readout`. */
export function withReadout(p: Float64Array, qubits: number, readout: number): Float64Array {
  if (readout === 0) return p;
  const reported = p.slice();
  for (let q = 0; q < qubits; q++) {
    const m = mask(q, qubits);
    for (let i = 0; i < reported.length; i++) {
      if (i & m) continue;
      const [zero, one] = [reported[i], reported[i | m]];
      reported[i] = (1 - readout) * zero + readout * one;
      reported[i | m] = (1 - readout) * one + readout * zero;
    }
  }
  return reported;
}
```

```ts
import { DENSITY_QUBITS, gateError, operationQubits, partwayMeasurements, type Circuit, type Condition, type Noise, type Operation } from '../circuit/model';
import { applySingle, applySwap, conjugate, gateMatrix, mask, type Amplitudes, type Matrix2 } from './kernels';

/** ρ in Qanvas's index order (q0 is the most significant bit), row-major: entry (i, j) is at i·2ⁿ + j. */
export interface DensityMatrix {
  qubits: number;
  re: Float64Array;
  im: Float64Array;
  mixed: true;
}

/**
 * Seen as a 2n-qubit vector, ρ's row index is qubits 0…n−1 and its column index is n…2n−1,
 * so UρU† is U on the row qubits followed by conj(U) on the column qubits.
 */
function asVector(rho: DensityMatrix): Amplitudes {
  return { qubits: 2 * rho.qubits, re: rho.re, im: rho.im };
}

/** `controls` are qubits; `columnBits` are bits of the 2n-qubit vector that control both sides. */
function applyUnitary(rho: DensityMatrix, m: Matrix2, target: number, controls: number[], columnBits: number[] = []) {
  const n = rho.qubits;
  applySingle(asVector(rho), m, target, [...controls, ...columnBits]);
  applySingle(asVector(rho), conjugate(m), n + target, [...controls.map((c) => n + c), ...columnBits]);
}

/** Removes the coherence between the qubit's 0 and 1: the state after measuring it, before anyone looks. */
function dephase(rho: DensityMatrix, qubit: number) {
  const dim = 1 << rho.qubits;
  const m = mask(qubit, rho.qubits);
  for (let i = 0; i < dim; i++) {
    for (let j = 0; j < dim; j++) {
      if ((i ^ j) & m) {
        rho.re[i * dim + j] = 0;
        rho.im[i * dim + j] = 0;
      }
    }
  }
}

/**
 * Splits off the part of a just-measured qubit whose reading came out wrong. The measurement left ρ with no
 * entries between the qubit's 0 and 1, so they hold that part: entry (i, j) means the qubit has i's value and
 * the reading says j's. Gates on other qubits treat both parts alike, and a condition reads j, the column.
 */
function misread(rho: DensityMatrix, qubit: number, readout: number) {
  const dim = 1 << rho.qubits;
  const m = mask(qubit, rho.qubits);
  for (let i = 0; i < dim; i++) {
    for (let j = 0; j < dim; j++) {
      if ((i ^ j) & m) continue;
      const right = i * dim + j;
      const wrong = i * dim + (j ^ m);
      rho.re[wrong] = readout * rho.re[right];
      rho.im[wrong] = readout * rho.im[right];
      rho.re[right] *= 1 - readout;
      rho.im[right] *= 1 - readout;
    }
  }
}

/** Adds the wrong-reading part back onto the qubit's own value, once no condition can read that measurement. */
function merge(rho: DensityMatrix, qubit: number) {
  const dim = 1 << rho.qubits;
  const m = mask(qubit, rho.qubits);
  for (let i = 0; i < dim; i++) {
    for (let j = 0; j < dim; j++) {
      if (!((i ^ j) & m)) continue;
      const wrong = i * dim + j;
      const right = i * dim + (j ^ m);
      rho.re[right] += rho.re[wrong];
      rho.im[right] += rho.im[wrong];
      rho.re[wrong] = 0;
      rho.im[wrong] = 0;
    }
  }
}

/** ρ → K₀ρK₀† + K₁ρK₁† with K₀ = |0⟩⟨0| and K₁ = |0⟩⟨1|: the |1⟩ block moves onto |0⟩. */
function reset(rho: DensityMatrix, qubit: number) {
  const dim = 1 << rho.qubits;
  const m = mask(qubit, rho.qubits);
  for (let i = 0; i < dim; i++) {
    for (let j = 0; j < dim; j++) {
      const k = i * dim + j;
      if ((i | j) & m) {
        rho.re[k] = 0;
        rho.im[k] = 0;
      } else {
        const from = (i | m) * dim + (j | m);
        rho.re[k] += rho.re[from];
        rho.im[k] += rho.im[from];
      }
    }
  }
}

/**
 * ρ → (1 − p)ρ + p·Tr_S(ρ) ⊗ I/2ᵏ on the k qubits S, Qiskit's depolarizing_error(p, k). With a condition,
 * only where the reading (the column bit, see `misread`) matches, so a gate that doesn't run adds no noise.
 */
function depolarize(rho: DensityMatrix, qubits: number[], p: number, condition?: Condition) {
  const n = rho.qubits;
  const dim = 1 << n;
  const offsets = Array.from({ length: 1 << qubits.length }, (_, s) => qubits.reduce((acc, q, b) => ((s >> b) & 1 ? acc | mask(q, n) : acc), 0));
  const touched = offsets[offsets.length - 1];
  const read = condition ? mask(condition.qubit, n) : 0;
  const share = p / offsets.length;
  for (let i = 0; i < dim; i++) {
    if (i & touched) continue;
    for (let j = 0; j < dim; j++) {
      if (j & touched) continue;
      if (condition && ((j & read) !== 0) !== (condition.value === 1)) continue;
      let traceRe = 0;
      let traceIm = 0;
      for (const o of offsets) {
        traceRe += rho.re[(i | o) * dim + (j | o)];
        traceIm += rho.im[(i | o) * dim + (j | o)];
      }
      for (const a of offsets) {
        for (const b of offsets) {
          const at = (i | a) * dim + (j | b);
          rho.re[at] = (1 - p) * rho.re[at] + (a === b ? share * traceRe : 0);
          rho.im[at] = (1 - p) * rho.im[at] + (a === b ? share * traceIm : 0);
        }
      }
    }
  }
}

const X = gateMatrix('X');

/** Runs `apply` where the reading of `condition.qubit` matches; `apply` gets the column bit that holds the reading. */
function whereRead(rho: DensityMatrix, condition: Condition, apply: (bit: number) => void) {
  const bit = rho.qubits + condition.qubit;
  if (condition.value === 0) applySingle(asVector(rho), X, bit, []);
  apply(bit);
  if (condition.value === 0) applySingle(asVector(rho), X, bit, []);
}

function applyGate(rho: DensityMatrix, op: Operation, noise: Noise | undefined) {
  if (op.gate === 'RESET') return reset(rho, op.targets[0]);
  if (op.gate === 'SWAP') {
    applySwap(asVector(rho), op.targets[0], op.targets[1]);
    applySwap(asVector(rho), rho.qubits + op.targets[0], rho.qubits + op.targets[1]);
  } else {
    const m = gateMatrix(op.gate, op.angle);
    if (op.condition) whereRead(rho, op.condition, (bit) => applyUnitary(rho, m, op.targets[0], [], [bit]));
    else applyUnitary(rho, m, op.targets[0], op.controls ?? []);
  }
  const error = gateError(op, noise);
  if (error > 0) depolarize(rho, operationQubits(op), error, op.condition);
}

/**
 * Writes the density matrix before any column, then after each one, into `re` and `im` (step k at k·4ⁿ),
 * so a long circuit keeps a single copy of each snapshot. Snapshots show the state with misread parts merged.
 */
export function simulateDensity(circuit: Circuit, re: Float64Array, im: Float64Array): void {
  if (circuit.qubits > DENSITY_QUBITS) throw new Error(`The density-matrix simulator works with up to ${DENSITY_QUBITS} qubits`);
  const n = circuit.qubits;
  const size = 1 << (2 * n);
  const partway = partwayMeasurements(circuit);
  const readout = circuit.noise?.readout ?? 0;
  const rho: DensityMatrix = { qubits: n, re: new Float64Array(size), im: new Float64Array(size), mixed: true };
  rho.re[0] = 1;
  const misreadQubits = new Set<number>();

  const save = (step: number) => {
    const snapshot: DensityMatrix = { qubits: n, re: re.subarray(step * size, (step + 1) * size), im: im.subarray(step * size, (step + 1) * size), mixed: true };
    snapshot.re.set(rho.re);
    snapshot.im.set(rho.im);
    misreadQubits.forEach((q) => merge(snapshot, q));
  };

  save(0);
  circuit.columns.forEach((column, c) => {
    for (const op of column) {
      for (const q of operationQubits(op)) if (misreadQubits.delete(q)) merge(rho, q);
      if (op.gate !== 'M') {
        applyGate(rho, op, circuit.noise);
        continue;
      }
      for (const q of op.targets) {
        if (!partway.has(`${c}:${q}`)) continue;
        dephase(rho, q);
        if (readout > 0) {
          misread(rho, q, readout);
          misreadQubits.add(q);
        }
      }
    }
    save(c + 1);
  });
}
```

```ts
  const key = measurementKey(condition.qubit, count[condition.qubit]);
```

````markdown
# quantum-lab: noise and counted qubits in `POST /run`

For a separate quantum-lab session. Qanvas doesn't modify quantum-lab; this is the change Qanvas 0.3 needs from the bridge (`bridge/bridge.py`, `bridge/runner.py`).

## Why

Qanvas simulates circuits with noise, measurements partway through or resets in the browser for up to 8 qubits. Larger ones need the lab's Qiskit Aer runner. Today `/run`:

- runs the OpenQASM without noise;
- counts every qubit that has any `measure`, so a qubit measured partway through and used again reports its old value.

Until the bridge has this change, Qanvas shows a size note for those circuits.

## Change

1. `GET /health` adds `"noise"` to `features`. Qanvas sends the new fields only when it sees it.
2. `POST /run` accepts two optional fields:
   - `noise`: `{"oneQubit": p1, "twoQubit": p2, "readout": r}`, each a probability. Reject values outside 0 ≤ p1, p2 ≤ 0.1 and 0 ≤ r ≤ 0.2 with a 400 and `{"error": {"code": "bad-request"}}`.
   - `measured`: the qubits to count, in the order of the result keys (q0 first, as today). Each counted qubit is read from its final measurement. If a counted qubit's last instruction isn't a measurement, the runner appends one into a new one-bit classical register. A qubit measured partway and then used again but not counted is left out of the keys.
3. With `noise`, the runner builds the same `NoiseModel` as Qanvas's Qiskit export (`src/code/qiskit.ts`):
   - `depolarizing_error(p1, 1)` on `["h", "x", "y", "z", "s", "sdg", "t", "tdg", "rx", "ry", "rz", "p", "u1"]`. Qanvas's OpenQASM writes P as `u1`.
   - `depolarizing_error(p2, 2)` on `["cx", "cz", "swap"]`.
   - `depolarizing_error(p2, 3)` on `["ccx"]`.
   - `ReadoutError([[1 - r, r], [r, 1 - r]])` on every measurement, mid-circuit ones included, so a condition can act on a wrong reading.
4. Run without optimization, so each Qanvas gate stays one instruction and gets its error once. Load with plain `qasm2.loads(qasm)`, which keeps Qanvas's `swap` as one instruction, and either don't transpile or use `transpile(qc, simulator, optimization_level=0)`. Checked on Oct 13, 2026: transpiling with the legacy custom instructions removes the SWAP entirely.
````

```ts
/** How many columns at the start keep the state pure: none resets, measures partway through or adds gate noise. */
function pureColumnCount(circuit: Circuit): number {
  const partway = partwayMeasurements(circuit);
  const first = circuit.columns.findIndex((column, c) =>
    column.some((op) => op.gate === 'RESET' || (op.gate === 'M' && op.targets.some((q) => partway.has(`${c}:${q}`))) || gateError(op, circuit.noise) > 0),
  );
  return first === -1 ? circuit.columns.length : first;
}
```

```ts
  // A density matrix has no global phase, so the pure steps are replayed on the state vector, to be
  // explained the same way as in a circuit that never needs the density matrix.
  if (isMixed(before) && step <= pureColumnCount(circuit)) {
    const states = simulate({ qubits: circuit.qubits, columns: circuit.columns.slice(0, step) });
    [before, after] = [states[step - 1], states[step]];
  }
```
